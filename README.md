### 📦 Open Source Highlights / 精选开源

> *"代码不该被藏起来。我相信开源的力量——它让知识自由流动，让创造者彼此启发。"*  
> 🌟 **7 年持续分享 · 50+ 开源项目 · 500+ GitHub Stars**

- [mina-popups](https://github.com/Yrobot/mina-popups) - 原生、轻量的小程序弹出组件集合，提供多样化弹窗和交互提示。
- [auto-scroll](https://github.com/Yrobot/auto-scroll) - 轻量级动态内容自动滚动工具，完美适配 AI 对话交互界面。
- [i18next-ssg](https://github.com/Yrobot/i18next-ssg) - 为 Next.js SSG 静态站点提供开箱即用的国际化支持方案。
- [FaaS.js](https://github.com/Yrobot/FaaS.js) - 基于 Bun 的文件即服务 (FaaS) Docker 镜像，快速将函数暴露为 API 服务。
- [react-mobile-table](https://github.com/yrobot-npm/react-mobile-table) - 基于 React 的移动端轻量可折叠数据表格组件。
- [cloudflare-search](https://github.com/Yrobot/cloudflare-search) / [cloudflare-proxy](https://github.com/Yrobot/cloudflare-proxy) - 基于 Cloudflare Workers 的高性能云端搜索与轻量代理服务。
- [mina-keyword-highlight](https://github.com/Yrobot/mina-keyword-highlight) - 零依赖小程序关键词高亮组件，支持文字样式继承与多行省略。
- [mina-countdown](https://github.com/Yrobot/mina-countdown) - 小程序轻量级倒计时控制库，支持暂停/恢复，适配短信验证码等场景。
